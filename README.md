# Prime Consulting Website

A premium, responsive one-page consulting website built with plain HTML, CSS and JavaScript.

## Open the website

Open `index.html` in a modern browser. No installation or build step is required.

## Important demo content

The company names, case studies, testimonials, client logos and team profiles are fictional demonstration content. Replace them with verified information and obtain permission before publishing real client names, logos, quotes, photos or results.

## Before publishing

1. Replace `YOUR_EMAIL@example.com` and `YOUR_NUMBER` in `index.html`.
2. Connect the consultation form to email, a CRM, Google Sheets or another form backend.
3. Replace demo projects, testimonials, logos and expert profiles.
4. Add real LinkedIn and social links.
5. Review compliance, legal and tax wording with qualified professionals.
6. Upload all four files together to GitHub Pages, Netlify, Vercel or standard hosting.

## Files

- `index.html` — content, sections, forms and SEO metadata
- `styles.css` — responsive layout, visual system and animations
- `script.js` — navigation, case-study dialogs and demo form behaviour
